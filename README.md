# Chinese IGame Guide

一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定域名或网站，仅作为静态页面的集合与展示。

## 项目简介

本仓库旨在收集、整理并发布一系列独立的 HTML 页面，这些页面可能涉及各类游戏相关指南、工具或信息展示。每个页面均为独立的静态文件，不依赖后端服务，可直接在浏览器中打开查看。

## 目录说明

```
/
├── pages/          # 存放所有独立 HTML 页面
├── assets/         # 页面引用的静态资源（图片、样式、脚本等）
├── index.html      # 可选的主页，用于导航或说明
└── README.md       # 本文件
```

- **pages/**：每个 HTML 文件为一个独立页面，文件名应反映页面内容或用途。
- **assets/**：按需存放页面所需的共用资源，建议子目录分类（如 `css/`、`js/`、`images/`）。
- **index.html**：可放置简单的目录或介绍页，便于浏览。

## 页面归档说明

- 所有页面均为静态 HTML，兼容主流现代浏览器。
- 页面之间无强制关联，可独立使用。
- 归档内容可能随时间更新或清理，不保证长期稳定性。
- 页面内容由贡献者自行维护，本仓库仅提供存储与分发。

## 维护说明

- 欢迎提交 Pull Request 添加新页面或改进现有页面。

- 页面文件命名建议使用英文小写与连字符，避免特殊字符。
- 资源文件请尽量使用相对路径，确保仓库克隆后可离线使用。
